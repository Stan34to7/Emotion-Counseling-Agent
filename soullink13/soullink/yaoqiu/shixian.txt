Workshop 定位

这个 workshop 不是传统意义上的绘画游戏，也不是艺术创作工具。
它在系统里承担的是“低门槛情绪外化与情绪重构”模块。
它的核心目标不是让用户画得好，而是让用户把当前难以直接说出的感受，转化成可操作、可观察、可调整的几何构图。
它必须是闭环系统的一部分，而不是一个孤立小游戏。
它要同时接收三类输入：当前情绪状态、当前对话语境、当前画面状态。
它要输出三类结果：最终画面、创作过程轨迹、可供后续个性化使用的状态摘要。
一句话产品定义

一个由 3D 数字人陪伴的情绪艺术小游戏，用户通过拖拽和编辑几何元素表达当前情绪，系统根据视频情绪识别、对话上下文和画面变化，持续给出支持性语言、非语言反馈和局部创作建议，并在最后引导用户完成一轮“情绪重构”。
核心体验目标

低门槛：不需要绘画能力，不需要复杂学习成本。
可表达：用户可以快速把“紧张、压抑、混乱、平静、释然”等感受映射到画面。
可陪伴：3D 数字人不是摆设，而是实时解释、鼓励、提示和陪伴。
可调节：用户不是只“表达完就结束”，而是会在系统引导下对情绪进行一次重构。
可记录：每次 session 结束后，系统能留下结构化数据，支持后续个性化。
单局完整流程

Phase 0: 进入与准备

用户进入 workshop 界面，摄像头开启，系统读取当前视频情绪状态。

3D 数字人用一句很轻的引导开场，比如“如果把你现在的感觉变成图形，它会是什么样子？”

系统显示一个空白画布，不强迫用户先说很多话。

Phase 1: 初始情绪外化建议

系统先给一个“建议性起点”，不是直接帮用户画完，而是提供一个起始视觉方向。

建议内容包括：推荐颜色组、推荐几何元素类型、推荐密度倾向、推荐构图气质。

例如：紧张状态下推荐更松散的布局、更柔和的轮廓、更低密度的画面；压抑状态下可以推荐较深色基调但允许留出空白区域。

这一步的目标是降低用户“我不知道怎么开始”的阻力。

Phase 2: 自由创作与持续陪伴

用户通过拖拽、旋转、缩放、复制、排列几何元素来表达当前感受。

3D 数字人持续以低打扰方式陪伴，不要像教学软件一样频繁打断。

系统一边看视频情绪，一边看画面变化，一边看用户是否停顿、犹豫、反复撤销、局部堆叠过密。

当系统检测到某些状态时，插入局部建议，比如“要不要试试把这块拉开一点”“你可以加一种更柔和的颜色看看”。

Phase 3: 局部引导与状态驱动建议

这一步不是新的页面，而是创作中途的智能提示层。

建议必须和当前画面直接相关，而不是泛泛说“继续加油”。

系统可以对画面中的一个局部区域给出建议，例如：某一区域过密、过尖锐、过单调、过对称、过压迫。

用户可以接受建议、忽略建议，或一键应用一个轻量修改模板。

Phase 4: 情绪重构

当用户完成第一次表达后，系统进入“重构”阶段。

这不是否定用户原来的表达，而是邀请用户思考：如果想让这幅画从“当前情绪”走向“稍微更舒服一点的状态”，愿不愿意改一小步。

系统提供 2 到 3 个可选方向，例如“柔化尖锐感”“降低拥挤感”“加入一点提亮色”“让构图更稳定一些”。

用户选择其中一个方向后，系统给出局部调整建议，用户再自行修改。

这个阶段是整个 workshop 最关键的“干预”部分。

Phase 5: 结束与反思

用户完成后，系统保存最终构图。

3D 数字人给出一段简短总结，不做临床判断，只做支持性反思。

用户可以选择一个轻量标签来描述作品，比如“更放松了”“还是有点乱”“比刚开始清楚一点”。

系统将本次作品、操作日志和摘要特征写回用户状态。

核心玩法元素

基础图形：点、线、面、圆形、矩形、三角形。
可选扩展：圆角矩形、波浪线、半透明色块、多边形。
基础操作：新增、拖拽、缩放、旋转、复制、删除。
构图操作：对齐、对称、重复、分布、层级前后调整。
情绪操作：颜色切换、密度调整、间距调整、尖锐度调整、留白调整。
辅助操作：撤销、重做、一键应用建议、一键生成初始模板。
界面建议

中央是主画布。
左侧是几何元素工具栏。
右侧是属性面板，包含颜色、大小、旋转、透明度、重复等。
右上角是 3D 数字人区域。
顶部显示当前 session 阶段，例如“开始表达”“继续调整”“情绪重构”。
底部显示轻量操作栏，比如“接受建议”“跳过”“完成本轮”。
3D 数字人如何参与

语言角色：开场引导、局部提示、鼓励继续、重构建议、结束总结。
非语言角色：点头、注视、停顿、手势、表情变化、说话节奏变化。
原则是“陪伴感强，控制感弱”。
它不能替用户做决定，但要让用户感觉“不是一个人面对空白画布”。
状态驱动逻辑

系统输入状态至少包括：
视频情绪状态：情绪类别、强度、置信度、变化趋势
对话状态：最近几轮文本、支持策略、用户回应风格
画面状态：颜色分布、形状种类、密度、对称性、尖锐度、留白比例
交互状态：编辑次数、停顿时长、撤销频率、接受建议次数
用户画像：偏好颜色、偏好形状、历史作品风格
系统输出建议至少包括：
语言建议：安抚、鼓励、反思、创作引导
视觉建议：颜色、形状、密度、间距、局部重构
具身反馈：表情、姿态、目光、语速
阶段推进：继续表达 / 进入重构 / 结束保存
建议引擎可以先做成规则式

如果 高紧张 + 画面尖锐度高 + 局部密度高，推荐“降低密度 / 增加间距 / 使用圆形元素”。
如果 低活跃 + 长时间停顿，推荐“先添加一个简单图形或一个颜色块”。
如果 反复撤销 + 局部修改频繁，推荐“锁定一块区域先完成，不必一次改完整张画”。
如果 画面已经稳定 + 用户操作速度下降，推荐进入重构阶段。
如果 重构后颜色更均衡、密度下降、尖锐元素减少，结束时给出“你已经让画面更稳定了一些”的反馈。
作品与过程数据结构

画布建议存成可回放 JSON，而不是只存图片。
最少要记录 shapes[] + operations[] + timestamps + summary_features。
一个 shape 对象可以包含：
{
  "id": "shape_001",
  "type": "triangle",
  "x": 320,
  "y": 180,
  "scale": 1.2,
  "rotation": 45,
  "color": "#D95C4A",
  "opacity": 0.9,
  "layer": 3
}
一个 session 摘要对象可以包含：
{
  "session_id": "sess_20260422_01",
  "affect_label": "tense",
  "affect_intensity": 0.78,
  "phase_reached": "reconstruction",
  "shape_count": 14,
  "density_score": 0.66,
  "symmetry_score": 0.31,
  "sharpness_ratio": 0.57,
  "dominant_palette": "warm_dense",
  "idle_seconds": 18,
  "suggestion_accept_count": 3
}
Workshop 的输出物

最终作品快照。
可编辑画布 JSON。
用户完整操作轨迹。
作品摘要特征。
简短反思文本或标签。
本轮系统建议及其是否被采纳。
对开发最重要的几个非功能原则

不做分数排名，不做胜负，不做“你画得好不好”的评价。
不强推系统建议，用户必须始终有跳过权。
不把情绪识别结果直接展示成生硬诊断。
不让 3D 数字人频繁打断创作。
不把 workshop 做成自由度过高的绘画软件，必须保持“简单几何 + 轻量操作 + 情绪引导”这个边界。
建议的 MVP 范围

第一版只做 2D 几何画布，不必一开始做复杂粒子或物理效果。
第一版只做 6 种图形、8 到 12 种颜色、3 个阶段。
第一版建议引擎用规则系统，不必立刻上复杂生成模型。
第一版 3D 数字人可以先支持 4 种反馈状态：平静、鼓励、关切、引导。
第一版先保证“能表达、能得到建议、能做一次重构、能保存过程”。
