# `personality/RESEARCH_NOTES.md`

```markdown
# Personality / Psychological Function Research Notes (Phase 2)

## Core scientific constraints

1. **Aggregation (Fleeson & Gallagher, 2009, PMC2791901):** Traits predict *mean* behavioral manifestations across situations better than single occasions.
2. **Longitudinal stability (Bleidorn et al., 2022, DOI 10.1037/bul0000365):** Rank-order stability rises then plateaus; facet/maladaptive measures less stable — caution for pathology-like inferences.
3. **Self-report ER/rumination:** Clinically important (meta-analytic differences) but insight/bias limited; chat ≠ formal DERS/ERQ/RRS scoring.
4. **Rejection sensitivity:** Established psychometric construct with validity debates/factor issues; do not score A-RSQ from conversation.

## Conversational inference policy

- Default band for functional constructs: `weak_only` at STATE/PATTERN.
- Many constructs marked `INSUFFICIENT_EVIDENCE_FOR_CONVERSATIONAL_INFERENCE` for TRAIT lock.
- Always separate value / confidence / stability.
```
