# 情绪几何工坊设计方案

## 1. 目标定位

“情绪几何工坊”不是纯绘画工具，也不是一次性小游戏，而是现有多模态情绪识别系统中的一个“轻量情绪外化与重构模块”。

它的核心目标有三个：

1. 把系统识别到的情绪状态转成低门槛的可视化创作任务。
2. 通过几何元素组合，让用户在不需要会画画的前提下完成表达。
3. 在第一次创作后引导一次“情绪重构”，帮助用户从作品中做微调，而不是停在宣泄阶段。

建议把它定义为：

`情绪识别 -> 参数推荐 -> 几何创作 -> 情绪重构 -> 作品分析 -> 历史记录`

## 2. 文献结论与可落地含义

### 2.1 你给的三篇核心文献

1. Trautmann, 2021, *Emotions Evoked by Geometric Patterns*  
   链接: https://www.mdpi.com/2571-8800/4/3/29

   可用结论：
   - 基础几何类型和排列方式会显著影响主观情绪感受。
   - 同一种基本元素，因重复方向、倾斜方式、密度和节奏不同，会呈现不同情绪印象。
   - 论文里对形状含义的总结非常适合做“参数推荐”的起点：圆形偏舒适、统一、保护；三角形偏行动、紧张、冲突；方形偏稳定、秩序、安全。

   对产品的直接启发：
   - 推荐的不是单个图形，而是一组“构成参数”。
   - 系统要同时控制形状、方向、密度、对称性、重复方式、留白比例，而不只控制颜色。

2. Bar and Neta, 2007, *Visual Elements of Subjective Preference Modulate Amygdala Activation*  
   链接: https://pmc.ncbi.nlm.nih.gov/articles/PMC4024389/

   可用结论：
   - 人们通常更偏好曲线轮廓，而尖锐、锐角轮廓更容易被感知为具有威胁性。
   - 论文提出尖锐轮廓可能触发更高警觉和威胁加工，这为“减少尖锐元素”的重构提示提供了理论支持。

   对产品的直接启发：
   - 当识别到焦虑、烦躁、紧绷、愤怒时，可以允许用户先使用尖角、断裂、斜切、放射状元素做表达。
   - 第二阶段重构可以引导用户降低尖锐度、减小对角冲突、增加曲线或圆角元素比例。

3. Rankanen et al., 2022, *Physiological measurements and emotional experiences of drawing and clay forming*  
   链接: https://www.sciencedirect.com/science/article/pii/S019745562200020X

   可用结论：
   - 快速绘画在生理指标上表现出较强放松效应。
   - 非指导式创作会带来更积极的情绪体验和创造性联想。

   对产品的直接启发：
   - 首轮创作不要过度解释，不要上来就让用户写很多字。
   - 推荐先给一个短时、低门槛、偏直觉式的“摆一摆”任务，再进入二次重构。

### 2.2 邻近文献补充

1. Tawil et al., 2022, *The contour effect*  
   链接: https://pmc.ncbi.nlm.nih.gov/articles/PMC9752057/

   可用结论：
   - 曲线轮廓在审美和压力感知上整体优于棱角轮廓，且对压力感受的影响更稳定。

   启发：
   - 如果小游戏目标包含“从高唤醒转向稳定”，曲线、圆角、柔和节奏、较大留白应作为重构方向。

2. Weinfeld-Yehoudayan et al., 2024, *A theoretical model of emotional processing in visual artmaking and art therapy*  
   链接: https://doi.org/10.1016/j.aip.2024.102196

   可用结论：
   - 艺术创作的作用不只在表达，还在于帮助个体完成情绪识别、接纳、意义化和再组织。

   启发：
   - “情绪重构”不是可有可无的彩蛋，而应该是这个模块的第二核心步骤。

3. Stickley et al., 2025, *The impact of doodling on cognition and affect: A scoping review*  
   链接: https://doi.org/10.1016/j.aip.2025.102368

   可用结论：
   - 涂鸦与随手画对情绪改善总体呈正向作用，但不同研究对“涂鸦”的定义并不一致。

   启发：
   - 我们可以把这个模块表述为“情绪表达与整理工具”，不要对外宣传成临床治疗。

## 3. 设计原则

1. 低门槛优先。用户不需要绘画技能，只需要拖拽、缩放、换色、复制、镜像、旋转。
2. 参数化而不是自由绘画。重点是构成关系，不是笔刷能力。
3. 表达优先于评判。第一轮先让用户外化情绪，第二轮再做温和重构。
4. 建议要可执行。不要说“让它更积极”，要说“把最尖的 3 个三角形换成圆形”。
5. 分析报告要解释“为什么”。不仅给标签，还要把视觉特征和情绪含义对应起来。
6. 明确边界。报告只能做“作品特征分析”和“情绪表达趋势提示”，不能替代心理诊断。

## 4. 推荐的游戏闭环

### 4.1 阶段 A：情绪进入

输入来源：

- 现有文本情绪识别
- 现有语音情绪识别
- 现有表情识别
- 现有融合情绪结果

输出内容：

- 主情绪：如平静、开心、难过、疲惫、焦虑、烦躁
- 唤醒度：低 / 中 / 高
- 方向性：向内收缩 / 向外释放

如果当前系统只有“开心 / 难过 / 疲惫 / 感激 / 平静”五类，建议新增一个轻量映射层，把融合情绪转成几何创作状态：

| 融合情绪 | 几何状态 |
| --- | --- |
| 开心 | 活跃扩张 |
| 难过 | 低能量收缩 |
| 疲惫 | 低刺激修复 |
| 感激 | 温和连接 |
| 平静 | 稳定整合 |

后续再扩展焦虑、烦躁、压抑等更细类别。

### 4.2 阶段 B：系统推荐一组几何风格参数

建议参数结构如下：

```json
{
  "shape_family": ["circle", "rounded_rect"],
  "accent_shape_family": ["triangle"],
  "palette": ["#7BC7B5", "#F5E6A8", "#F2B3A9"],
  "symmetry": "horizontal_soft",
  "density": 0.35,
  "rhythm": "even",
  "rotation_bias": 8,
  "sharpness": 0.2,
  "blank_ratio": 0.4,
  "element_count_range": [6, 14],
  "prompt": "先摆出一种此刻的呼吸感，不追求好看。"
}
```

推荐逻辑示例：

| 情绪状态 | 形状 | 构成 | 颜色 | 交互引导 |
| --- | --- | --- | --- | --- |
| 平静 | 圆、圆角矩形 | 对称、中低密度、大留白 | 低饱和冷暖中性色 | “试着让画面像在稳定呼吸” |
| 难过 | 下沉圆、竖向矩形、少量散点 | 稀疏、下坠、偏单侧 | 灰蓝、雾紫、低亮度 | “把沉重感摆出来就可以” |
| 疲惫 | 大块圆角面、少量重复 | 低复杂度、节奏慢 | 米白、浅灰绿、低对比 | “让画面先变得没那么累” |
| 开心 | 圆、弧线、跳跃点阵 | 放射、重复、节奏快 | 明亮暖色与高明度对比 | “让元素轻轻弹起来” |
| 焦虑/烦躁 | 三角、折线、斜切矩形 | 高密度、倾斜、局部拥挤 | 高对比补色或冷暖冲突 | “先把紧绷感摆出来，再慢慢整理” |

### 4.3 阶段 C：自由组合创作

建议只提供少量基础元素：

- 点
- 直线
- 曲线
- 圆
- 方形
- 圆角矩形
- 三角形
- 半圆
- 色块面

建议只提供少量操作：

- 拖拽
- 缩放
- 旋转
- 复制
- 删除
- 改色
- 改透明度
- 镜像
- 一键重复
- 一键对称
- 置顶 / 置底

这样能保证低学习成本，同时保留足够的构成空间。

### 4.4 阶段 D：情绪重构

这是模块最关键的设计点。

系统先分析用户的首轮作品，再生成 1 到 3 条非常具体的重构建议。

示例建议：

- 把画面里最尖锐的 2 个元素换成圆形，看看紧张感会不会下降一点。
- 把右上角最密的区域拉开一点，给画面留一块能呼吸的空白。
- 保留主色不变，只把最刺眼的颜色降一点饱和度。
- 试着复制一个你最喜欢的元素，做成有节奏的重复。
- 如果愿意，可以让画面增加一点左右平衡感。

重构阶段要支持对比：

- 原始作品缩略图
- 重构后作品缩略图
- 自动生成“变化摘要”

### 4.5 阶段 E：分析报告与历史记录

报告建议分成四块：

1. 作品描述  
   例：你的作品以高密度斜向三角形和局部对撞色为主，整体呈现较高张力。

2. 特征解读  
   例：较多尖角、倾斜布局和局部拥挤通常会传递紧张、警觉和未整理的能量。

3. 重构变化  
   例：你在第二轮减少了尖锐元素，增加了留白和重复节奏，画面的压迫感下降，秩序感上升。

4. 历史趋势  
   例：相比上次，本次作品的对称性提升、密度下降，说明你更倾向于把情绪整理成稳定结构。

## 5. 作品分析模型

建议不要一开始就上复杂 CV 模型。第一版完全可以基于结构化编辑数据分析。

### 5.1 存什么数据

每个元素记录：

- shape_type
- x
- y
- width
- height
- rotation
- fill_color
- stroke_color
- opacity
- corner_radius
- z_index
- created_at
- copied_from

每次编辑动作记录：

- add
- move
- resize
- rotate
- recolor
- duplicate
- delete
- group_repeat
- symmetry_apply
- undo

### 5.2 从数据提哪些特征

静态画面特征：

- 圆形占比
- 三角形占比
- 尖锐度指数
- 曲率指数
- 对称度
- 密度
- 留白率
- 色彩饱和度均值
- 色相跨度
- 亮度对比
- 重复度
- 节奏规则性
- 旋转离散度
- 中心偏移量

动态过程特征：

- 总编辑时长
- 首次出图时间
- 复制次数
- 删除次数
- 撤销次数
- 重构阶段改动幅度
- 从尖锐到圆润的变化量
- 从拥挤到疏散的变化量

### 5.3 第一版报告生成方式

建议采用“规则引擎 + 模板生成”，不要第一版就依赖大模型。

规则示例：

- 若 `sharpness > 0.65` 且 `density > 0.7`，则说明“紧张和压迫感较强”
- 若 `blank_ratio > 0.45` 且 `symmetry > 0.6`，则说明“稳定与整理倾向增强”
- 若 `repeat_score` 上升，则说明“情绪开始被组织成节奏”
- 若二次重构后 `sharpness_delta < 0` 且 `blank_ratio_delta > 0`，则说明“从高唤醒转向缓和”

第二版再考虑：

- 用 LLM 把结构化特征转成更自然的中文反馈
- 但保留规则层作为可解释基础

## 6. 如何接到当前系统

从当前仓库看，现有模块已经具备：

- Flask 后端
- `/api/emotion/text`
- `/api/emotion/speech`
- `/api/emotion/face`
- `/api/emotion/fuse`
- 前端单页 `HTML + CSS + JS`

因此最稳妥的接入方式是：

### 6.1 前端

新增一个独立页面或独立区块：

- `frontend/geometry-workshop.html`
- `frontend/static/js/geometry-workshop.js`
- `frontend/static/css/geometry-workshop.css`

建议优先做“独立页面”，原因：

- 当前主页已经承载录音、摄像头、情绪展示、陪伴回复，继续塞会太重。
- 独立页面更适合画布交互、工具栏和重构流程。
- 主页面只需要增加一个“进入情绪几何工坊”的按钮。

### 6.2 后端接口

建议新增以下接口：

- `POST /api/geometry/recommend`
  输入：融合情绪结果
  输出：几何参数推荐

- `POST /api/geometry/analyze`
  输入：作品 JSON、重构前后差异、当前情绪
  输出：结构化分析结果

- `POST /api/geometry/report`
  输入：分析结果、历史摘要
  输出：用户可读报告

- `POST /api/geometry/save`
  输入：作品、分析、报告、时间戳
  输出：保存状态

- `GET /api/geometry/history`
  输入：用户标识
  输出：历史作品摘要列表

### 6.3 数据存储

第一版建议用 JSON 文件或 SQLite，不建议一开始上复杂数据库。

建议结构：

- `data/geometry_sessions/<user_id>/<session_id>.json`
- 或 `data/geometry_workshop.db`

每次记录：

- 检测到的融合情绪
- 推荐参数
- 初稿作品
- 重构后作品
- 自动分析
- 最终报告
- 时间戳

## 7. MVP 范围

第一版只做最必要的闭环：

1. 接受现有融合情绪结果。
2. 返回一组几何推荐参数。
3. 提供基础几何拖拽画布。
4. 支持复制、镜像、旋转、重复、改色。
5. 支持一次情绪重构提示。
6. 生成规则式报告。
7. 保存到历史记录。

第一版暂时不做：

- 实时多人
- 复杂图层编组
- 手绘笔刷
- AI 自动生成整幅图
- 临床级评估结论

## 8. 开发顺序建议

### Phase 1：先跑通创作闭环

- 做独立页面和画布
- 做基础图元编辑
- 做推荐参数面板
- 做作品 JSON 存储

### Phase 2：补分析与重构

- 提取静态构图特征
- 生成重构建议
- 输出前后对比报告

### Phase 3：接历史与个性化

- 汇总用户多次作品特征
- 做趋势变化摘要
- 用历史偏好修正推荐参数

### Phase 4：做实验与论文支撑

- 记录完成时长、编辑次数、重构接受率
- 对比“有重构提示”和“无重构提示”的差异
- 分析不同情绪状态下的参数偏好与作品特征

## 9. 风险与注意事项

1. 不要把“几何特征 = 精准心理诊断”写死。它更适合作为表达线索，而不是诊断工具。
2. 不要把报告写得像算命。报告必须引用具体画面特征。
3. 不要一开始给太多元素。元素太多会让低门槛目标失效。
4. 不要让重构变成纠错。语气要像“邀请整理”，不是“评判你画得不对”。
5. 如果后续要做论文实验，必须保留推荐参数、操作日志和前后作品差异。

## 10. 结论

这个小游戏很适合放进你现在的系统，而且不是附属装饰，而是能明显增强“情绪识别之后做什么”的核心链路。

最推荐的产品定义是：

`把识别到的情绪，转成一组可操作的几何构成任务，并通过二次重构把表达推进到整理。`

如果继续开发，最合理的下一步不是先做复杂 AI，而是先做一个能跑通的 MVP：

- 情绪转参数
- 几何画布
- 重构提示
- 分析报告
- 历史记录

这样既符合文献，也最适合你当前项目结构。
