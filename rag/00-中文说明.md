# 临床心理知识资产包 · 中文使用说明

案例实践一_面向情绪疏导的情智互动数字人构建课题知识库构建提供的专业知识语料，来源于临床心理评估项目（原"交接包 B"）

## 一、精简说明

- 知识卡片本体（knowledge-cards/，18 张可运行卡片）
- 可读正文（全文/，含知识卡片正文、规程可读版、来源登记全文）
- 专业来源登记（professional-sources/）
- 说明文件（00-交接说明、01-知识卡片目录、02-来源与全文说明、PURPOSE.md）

## 二、包内结构

```text
00-中文说明.md            # 本文件
00-交接说明.md            # 交接说明（含精简后结构）
01-知识卡片目录.md        # 知识卡片一览
02-来源与全文说明.md      # 来源与全文说明
PURPOSE.md               # 项目目的
knowledge-cards/         # 知识卡片 YAML（provisional-runtime/ 下 18 张）
全文/知识卡片/            # 知识卡片可读正文（Markdown）
全文/规程/               # 问诊/风险/人格等规程的可读版（来自已删源文件的正文抽取）
全文/来源登记全文.md      # 专业来源登记（含官方链接）
professional-sources/    # 来源登记与官方来源指针（APA、ICD-11、mhGAP、NICE、RDoC 等）
```

## 三、内容主题

知识卡片覆盖抑郁、焦虑、双相、ADHD、精神病性、自伤风险、人格与状态区分等主题，每张卡片包含结论边界与依据，例如：

- 情绪低落不足以诊断抑郁障碍（DEP_MOOD_001）
- 睡眠需求减少与失眠的区分（BIP_SLEEP_001）
- 风险量表不能用于预测自伤（SH_RISK_001）
- 单次表述不能推断人格特质（STATE_TRAIT_001）

## 四、作为知识库材料怎么用

1. **语料组织**：以 `全文/知识卡片/` 的可读正文为主，组织成"问题—结论—依据—来源"文本块；`knowledge-cards/` 下的 YAML 提供结构化字段，可按需转换。
2. **清洗入库**：将卡片文本清洗、去重、分块，经 BGE 嵌入模型向量化后存入 FAISS 向量库，实现 Top-k 检索与智能问答。
3. **用途定位**：本包是知识库的"专业知识点"语料（情绪状态判断、症状边界、风险警示），需与心理疏导话术、情绪调节方法等学生自搜语料合并使用，不单独构成完整知识库。
4. **风险处理**：自伤风险相关卡片（SH_RISK_001/002）建议做成固定转介模板（如"建议联系专业机构"），不交由大模型自由生成。

## 五、注意事项

- 卡片多为 PROVISIONAL_RUNTIME（来源与结构已核验，未作专家终审）。教学演示可保留来源标注，但不得声称具备临床诊断能力。
- 官方手册全文不在包内（受版权限制），来源与官方链接见 `全文/来源登记全文.md` 与 `professional-sources/`。
- 心理测量工具题目原文不随包提供。
- 本包是教学用知识语料，不是已注册医疗器械，不能用于实际临床诊断。
